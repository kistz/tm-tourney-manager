# Welcome
This project aims to be a centralized but free (as in freedom aswell as free of charge) and open-source data platform for everything around Trackmania 2020 servers.
It was specifically designed to make hosting tournaments as easy as possible only requiring you to connect your own servers.

To use it you only have to sign in via your trackmania account.
Afterwards you can freely create projects/tournaments

In this guide we will aim to familiarize you with the basic concepts on how to use the tool yourself such as the Node Based Architecture and the Features.
